# Приватность

- **API-ключи и токены** (провайдеры, MCP, OAuth, Relay) хранятся только в `expo-secure-store`, то есть в Android Keystore. Ключ доступен, только пока устройство разблокировано. Ключи не попадают в SQLite, логи, резервные копии и синхронизацию.
- **Чаты, проекты и статистика** хранятся в локальной базе SQLite на телефоне. На ПК они попадают, только если вы сами нажмёте «Синхронизировать» в разделе «Компьютер».
- **Сетевые запросы** идут только к выбранному провайдеру ИИ, к вашим MCP-серверам и Relay, а также к публичному списку цен OpenRouter (без ключа), курсам валют open.er-api.com и GitHub Releases (проверка обновлений, можно выключить).
- **Телеметрии нет.**
- **Инструменты** вызываются только с вашего подтверждения, пока вы не выберете «Всегда разрешать». Результаты инструментов передаются модели как данные. В системном промпте модель предупреждена не выполнять инструкции из этих данных.
- **Блокировка**: при включённой биометрии приложение блокируется при запуске и после минуты в фоне.
- **Удаление**: Настройки → Приватность → «Удалить все данные» стирает базу и все секреты.

## Nexus Desktop

- API-ключи шифруются через Electron `safeStorage` (Windows DPAPI, macOS Keychain, Linux libsecret/kwallet) и хранятся в `keys.json` только в зашифрованном виде; если хранилище ОС недоступно, ключ сохраняется в base64 с пометкой `plain:`.
- Чаты, статистика и настройки — JSON-файлы в папке данных приложения (Настройки → Общие → «Папка данных»). Запись атомарная, повреждённый файл сохраняется рядом, а не удаляется.
- Инструменты ПК видят только разрешённые папки. Запись файлов, буфер обмена, открытие ссылок и команды требуют подтверждения; команды выключены по умолчанию, выполняются без оболочки и только из белого списка (если он задан).
- Встроенный Relay выключен по умолчанию. Подключение телефона — только по одноразовому QR-коду, каждое устройство можно отключить.
