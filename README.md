# Конструктор занятий ДОУ (Android)

Приложение для воспитателей и логопедов детского сада. Собирает занятие по лексической теме недели: **рабочий лист**, **конспект** и **задание для родителей** (4–5 упражнений на дом). Технологическая карта не составляется.

**APK:** [`release/Konstruktor-DOU-v1.0.0.apk`](release/Konstruktor-DOU-v1.0.0.apk) (Android 7.0 и новее).

## Возможности

| | |
|---|---|
| Направления | развитие речи, ФЭМП (математика), окружающий мир, обучение грамоте, комплексное |
| Возраст | средняя (4–5), старшая (5–6), подготовительная (6–7) группа |
| Темы | 36 лексических тем, сентябрь–май, плюс своя тема |
| Усложнение | уровень 1–36: месяц × неделя × возраст. Математика: счёт до 3 → до 20, состав числа, примеры, задачи, часы, графический диктант |
| Логопедия | группа общеразвивающая / комбинированная / логопедическая, ползунок 0–100 %, речевое заключение, звук для автоматизации |
| Заданий | 52 типа: речь, математика, грамота, окружающий мир, логопедия, моторика (лабиринты, обводка) |
| ИИ (текст) | DeepSeek (по умолчанию), OpenRouter, OpenAI, Groq, Mistral, любой OpenAI-совместимый API — по ключу |
| ИИ (картинки) | эмодзи (без интернета), пиктограммы ARASAAC, Pollinations.ai по ссылке (бесплатно), OpenAI-совместимый API картинок по ключу |
| Экспорт | Word (.docx с картинками), PDF через печать, «Отправить» |
| Прочее | история занятий, резервная копия JSON, «План года» с программой по месяцам, просмотр промпта |

Без интернета всё работает на встроенном генераторе. ИИ переписывает и дополняет любой из трёх документов по промпту из [`PROMPT.md`](PROMPT.md).

## Подключение нейросетей

1. **Настройки → Текстовая нейросеть**: выберите DeepSeek, вставьте ключ с https://platform.deepseek.com/api_keys, нажмите «Проверить подключение».
2. **Настройки → Картинки**: выберите Pollinations.ai (ссылка уже вписана, ключ не нужен) или нейросеть по ключу (например, `https://api.openai.com/v1`, модель `dall-e-3`).
3. В «Занятии» нажмите «✨ ИИ-версия» или «✨ Всё с ИИ».

Ключи хранятся только на телефоне.

## Сборка

```bash
sudo apt-get install -y openjdk-17-jdk-headless aapt dalvik-exchange zipalign apksigner curl
./android/build.sh        # → release/Konstruktor-DOU-v<версия>.apk
```

Структура: `android/src` — нативная оболочка (WebView и мост для HTTP, файлов, печати), `android/assets/www` — приложение (`data.js` — темы и годовые планы, `gen.js` — генератор, `docx.js` — экспорт Word, `app.js` — интерфейс и API).

Ключ подписи `android/keystore/konstruktor.jks` (пароль `konstruktor-dou`) лежит в репозитории, чтобы обновления ставились поверх старой версии. Для публикации в магазине замените его своим.
